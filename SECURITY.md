# Security policy

Do not report bridge tokens, upstream credentials, signed URLs, or personal catalogue activity in public issues. Rotate a credential immediately if it may have been exposed.

Report vulnerabilities privately through GitHub's security advisory interface for this repository. Include the affected commit, reproduction steps using synthetic data, and expected impact.

Atlas Bridge treats all upstream responses as untrusted. It does not promise anonymity, legal authorization, or upstream availability. Operators are responsible for lawful use and for keeping the service on a private network.
